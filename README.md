# Jayesh Chaudhari — Portfolio

A fresh React + TypeScript portfolio inspired by the visual character of my earlier site. Source and history are independent of the old portfolio.

**Live:** https://jayeshchaudhari1210.github.io/portfolio/

## Development

Use Node.js 24 or newer.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

GitHub Actions builds and publishes the static site to GitHub Pages. Vite's base is `/portfolio/`. Contact links open email, LinkedIn, GitHub or the existing résumé; no form data is collected.

Project descriptions distinguish alpha software, early utilities and documentation-only work. Learning resources are bookmarks, not claims of authorship. Original project contributors retain their credit.
